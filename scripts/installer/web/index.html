自订网址

需要教会自己有网域，而且有人能改它的 DNS 设定。只能用子网域（例如 staff.hope-church.org），不能只填 hope-church.org。没有的话留空，继续用原本的 .pages.dev 网址。

建置新版网站大约要 10–20 分钟，这段时间旧版网站照常可以用。中途停止或失败都不会影响旧版，重新按「开始更新」即可。

      这只是测试安装？如何删除

      只删除下列这次建立的两个项目，不要删其他专案。删除要在官方网站由你本人操作。

      1. Cloudflare 网站 ：开启网站专案页，按上方「Settings」，再按右侧「General」，在最下方按红字「Delete」并输入网站名称确认。立即永久删除，网站会马上消失。
      2. Google 专案 ：开启专案设定页，按上方「Shut down」（关闭），输入专案 ID 后按「Shut down anyway」。Google 会保留约 30 天才永久删除，期间可还原。

      顺序：先删 Cloudflare 网站，再关闭 Google 专案。正式使用的站请勿删除。
