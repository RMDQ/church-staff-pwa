# 教会服事表 App 安装教学：程式小白也能自己架设，同工服事一目了然（附图解）

排服事表、找同工、整理名单，常常卡在 LINE 群组和好几份试算表之间。所以我为教会做了一个服事用的 App，现在整理成不会写程式也能自己装的版本，分享给需要的教会。

这篇教学写给**没有工程背景的教会同工**。整个安装都在浏览器里完成，不用在电脑上装任何软体，也不需要 GitHub 帐号。网站和资料都放在**你们教会自己的帐号**里，不经过我。

---

## 这个 App 可以做什么

【插入图 00｜00-app-overview.png】
图说：左边是同工打开看到的首页，右边是服事表。首页的「行事历」要另外串接 Google 日历，这一版还不包含（见下方说明）。画面里的教会和人名都是示范用的。

- **同工打开就看到自己接下来的服事**：哪一天、哪一场聚会、负责什么，不用再去 LINE 群组里翻。
- **服事表依聚会分页**：主日、青年崇拜各一页，每周谁负责什么一目了然。
- **排服事的人直接在 App 里排**：新增服事项目、指派同工，改完大家打开就是新的。
- **每位同工有自己的帐号**：管理员帮忙建立，同工登入后只会看到自己参与的聚会。
- **聚会可以自己调**：新增聚会、改星期几、停用不再举行的聚会，都在 App 里完成。
- **可以加到手机桌面**：从桌面的图示打开，用起来就像一般的 App。

另外还有**行事历**（首页显示教会近期活动）、**每日灵粮**，以及**拍照汇入整季服事表**。这些要多串接其他服务，这一版先不包含，之后可以请懂技术的同工另外打开。

## 安装前先准备

- **一个 Google 帐号**：用来建立存放资料的 Firebase 专案。**用个人的 Gmail 就可以**；网站会挂在这个帐号底下，装完精灵会给你一张「交接卡」记下来。
- **一个 Cloudflare 帐号**：用来放网站，免费注册即可（cloudflare.com）。
- **首位管理员能收信的 email**：安装完会寄一封设定密码的信到这里。
- **一台电脑**：用 Chrome 浏览器最顺。第一次安装抓 30 分钟到 1 小时比较保险。

几个你可能会担心的问题：

- **要付钱吗？** 安装精灵**不会绑定信用卡，也不会升级付费方案**。如果平台要求付费，或你们的组织帐号有限制，精灵会停下来说明原因，不会自己往下做。
- **中途要自己操作什么吗？** 有两个地方 Google 规定要本人在 Firebase 官网按：这个 Google 帐号第一次用 Firebase 时要同意条款，还有启用登入功能。精灵会停下来告诉你按哪里，各花一两分钟，后面有图文步骤。
- **会动到我们现有的网站吗？** 不会。精灵只建立**全新的专案**，不会接管或修改你们已经在用的网站或资料库。
- **密码会被看到吗？** Google 和 Cloudflare 的密码都只在它们的**官方网页**输入，精灵看不到。

## 第一步：打开 Cloud Shell

Cloud Shell 是 Google 免费提供、开在浏览器里的一台小电脑。安装精灵就在这里面执行。

1. 打开专案页面：https://github.com/hansli112/church-staff-pwa
2. 在页面最上面「不会写程式？用安装精灵」下面，按蓝色的「**Open in Google Cloud Shell**」按钮。

【插入图 01｜01-open-in-cloud-shell.png】
图说：在专案页找到这颗蓝色按钮。

3. Google 会问要不要「信任存放区」。**一定要先勾选「信任存放区」，再按「确认」。**

【插入图 02｜02-trust-repo.png】
图说：先勾选「信任存放区」，再按「确认」。这一步最容易漏掉。

4. 接著跳出 Google 官方的「授权 Cloud Shell」视窗，请按「**授权**」，不要按拒绝。之后如果再看到同样的视窗，也一样按「授权」。

【插入图 03｜03-authorize-cloud-shell.png】
图说：这是 Google 官方的视窗，让 Cloud Shell 用你自己的帐号建立专案。

### 如果左上角出现「暂时模式」

没勾到「信任存放区」的话，Cloud Shell 左上角会显示「**暂时模式**」，精灵就没办法帮你建立专案。处理方式：

1. 按右上角的「⋮」，点选单里**打勾的「暂时模式」**。

【插入图 04｜04-ephemeral-menu.png】
图说：左上角有「暂时模式」字样，就从右上角「⋮」把它关掉。

2. 按「**停用**」。

【插入图 05｜05-ephemeral-disable.png】
图说：按「停用」，Cloud Shell 会重新启动。

3. Cloud Shell 重新启动、请你按「授权」之后，回到专案页**重新按一次**「Open in Google Cloud Shell」，这次记得勾选「信任存放区」。

## 第三步：连接 Google 和 Cloudflare 帐号

精灵打开后，第一区是「连接你的帐号」。

【插入图 10｜10-connect-accounts.png】
图说：先按「连接 Google」，再按「连接 Cloudflare」。

### 连接 Google

1. 按「**连接 Google**」，接著切到 Cloud Shell 分页。
2. 出现「Authorize Cloud Shell」时按 **Authorize**，选你这次要用的 Google 帐号。没出现的话，回精灵再按一次「连接 Google」。
3. 精灵会显示「已连接：你的 email」。**如果不是你要用的帐号，先停下来**，照精灵上的说明换帐号后再重新开始。

### 连接 Cloudflare

1. 按「**连接 Cloudflare**」，精灵会显示一组**代码**，再按「**开启官方授权页**」。

【插入图 11｜11-cloudflare-code.png】
图说：记下这组代码，再按「开启官方授权页」。精灵会倒数代码剩多少时间。

2. 在 Cloudflare 官方网页，把**精灵显示的代码**输入到框框里，按 **Continue**。还没登入的话，这时才会请你登入（可以用 Google 帐号登入）。登入后按 **Authorize**。

【插入图 12｜12-cloudflare-enter-code.png】
图说：页面上说的「terminal」指的就是安装精灵，把精灵上的代码填进来。

3. 看到「Authorization granted」就完成了。页面上其他英文说明（例如 AI 工具）都不用理，这个分页可以关掉，回到精灵。

【插入图 13｜13-cloudflare-granted.png】
图说：Cloudflare 授权成功的画面。

> 代码大约 5 分钟内有效。如果过期了，回精灵再按一次「连接 Cloudflare」拿新代码，**不要授权旧的代码**。

> **还没有 Cloudflare 帐号？** 在登入页按「Sign up」免费注册，Cloudflare 会寄一封验证信，点信里的连结完成验证。之后回到精灵，**重新按一次「连接 Cloudflare」**拿新的代码再做一次。

## 第四步：填写教会资料

【插入图 15｜15-church-settings.png】
图说：填完后按「检查并预览安装」。

- **教会／App 名称、桌面图示简称**：会显示在 App 和手机桌面图示上。
- **网站名称**：网址会是「网站名称.pages.dev」，同工要用这个网址登入，所以取个好记的，例如 `grace-church-staff`。只能用英文小写、数字和连字号（-），**建立后不能改**。如果这个名称已经被别人用过，Cloudflare 会在后面自动加几个字，实际网址以完成页为准。
- **教会时区**：决定服事表的日期，台湾是 `Asia/Taipei`。
- **资料库地区**：资料存放的地方，台湾选「台湾 · asia-east1」。**建立后不能改**，请确认再按。
- **每周聚会**：每一种聚会的简称、全名和固定星期几，例如「主日／主日崇拜／星期日」。有好几种聚会就按「新增一种聚会」。先填目前有的就好，装好之后可以在 App 里随时新增或修改。
- **首位管理员**：姓名和 email。这里**不用设定密码**，装好后会用官方信件设定。

按「**检查并预览安装**」。

### 如果停在「待本人操作」：第一次用 Firebase，要同意条款

有两个设定 Google 规定要**本人在官方网页按**，精灵没办法代按。第一个是同意 Firebase 条款：这个 Google 帐号**从没用过 Firebase** 的话，精灵会在「将 Firebase 加入新专案」这一步停下来。每个帐号只需要做一次，用过 Firebase 的帐号不会出现。

1. 按精灵上的「**开启官方设定页**」，用**同一个 Google 帐号**打开 Firebase 官网，按「**如要开始使用，请设定 Firebase 专案**」。

【插入图 18｜18a-firebase-welcome.png】
图说：第一次用 Firebase 会看到欢迎页，按左边这张卡片。

2. 跳出「建立专案」视窗。**不要在「输入专案名称」栏打字**（那会另外建一个新专案），改按最下方的「**将 Firebase 新增到 Google Cloud 专案**」。

【插入图 18｜18b-firebase-add-to-cloud.png】
图说：按最下方这行蓝字，不是「继续」。

3. 选精灵建好的「**Church Staff**」专案（专案 ID 是 church- 开头的那串，精灵画面上也看得到），勾选「**我接受《Firebase 条款》**」，一路按继续。问到 Google Analytics 选不启用，也不要升级付费方案。
4. 看到 Firebase 专案首页就完成了。回到精灵，按「**核对后接续安装**」。

【插入图 18｜18c-firebase-project-ready.png】
图说：左上角显示「Church Staff」和「Spark 方案」（免费方案），就可以回精灵了。

【插入图 18｜18-firebase-waiting.png】

【插入图 20｜20-firebase-providers-shown.png】

## 常见问题

**Q：中途不小心关掉了怎么办？**
不小心在终端机按到 Ctrl+C、重新整理或关掉 Cloud Shell 分页，精灵都会停下来，精灵页面会变成英文的「Unable to forward your request to a backend」。**进度都还在**，不用另外输入 `gcloud auth login` 之类的指令。重新做「第二步」（按同一张指令卡），点终端机给的**新**连结，连接**同一组** Google 和 Cloudflare 帐号，在「接续之前中断的安装」选原本的纪录。精灵会先核对云端上的实际状态，不会另外建一个专案。

**Q：只是想先试试看，装完要怎么删？**
完成页最下面有「这只是测试安装？如何删除」，只会列出这次建立的两个项目。

【插入图 34｜34-cleanup-steps.png】
图说：先删 Cloudflare 网站，再关闭 Google 专案。正式使用的站请不要删。

- **Cloudflare 网站**：打开网站专案页，按上方「Settings」→ 右侧「General」→ 最下方红字「Delete」，输入网站名称确认。**立即永久删除。**

【插入图 35｜35-cloudflare-delete.png】
图说：Settings → General → Delete。

- **Google 专案**：打开专案设定页，按上方「Shut down」，输入专案 ID 后按「Shut down anyway」。Google 会保留约 **30 天**才永久删除，这段期间还能还原。

【插入图 36｜36-google-shutdown.png】
图说：输入画面上显示的专案 ID，再按「Shut down anyway」。

**Q：有新版本怎么更新？**
有新版本时，管理员在 App 的「我的」页面会看到「有新版本可以更新」。更新方式跟安装差不多：

1. 照「第一步」「第二步」重新打开安装精灵。
2. 照「第三步」连接**当初安装用的** Google 和 Cloudflare 帐号（不确定的话看交接卡）。
3. 在「已经装过了？更新到新版本」按「**寻找已安装的网站**」，选你们的网站。
4. 勾选确认，按「**开始更新**」，大约 10–20 分钟。

更新**只会换网站程式**，同工帐号、服事表和所有资料都不会变。更新期间旧版照常可以用，中途失败也不会影响旧版。

**Q：想换成教会 Logo，或用自己的网址？**
在更新时展开「换教会 Logo、设定自订网址（选填）」就可以设定，不用另外找懂技术的人：

- **教会 Logo**：选一张图片（正方形最好）和底色，精灵会自动做好各种尺寸。手机桌面上已经加的图示要删掉重新加，才会换成新的。
- **自订网址**：教会自己有网域、而且有人能改 DNS 时才需要。填像 `staff.你们的网域` 这样的网址，更新完成后照画面上的说明加一笔 DNS 记录即可。

**Q：要新增聚会（例如祷告会），或聚会改到别天？**
管理员到 App 的「**我的**」→「**聚会设定**」就可以新增、改名称、改星期几，或停用不再举行的聚会，改完按右上角 ✓ 储存，所有人的 App 下次打开就会换成新的设定。

【插入图 37｜37-service-settings.png】
图说：「聚会设定」画面。关掉开关就是停用；按住右边的把手可以调整服事表分页的顺序。

- 改星期：已经排好的日期不会搬动，从下一个还没排的那周开始用新的星期。
- 停用：不再出现在服事表上，旧资料都会保留，之后可以再开启。

**Q：想加行事历、每日灵粮等其他功能？**
这些目前还需要懂技术的同工照专案里的部署指南处理。
