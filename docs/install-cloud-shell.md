# 用安装精灵建立同工助手

这份教学给没有工程背景的教会同工。整个安装在**你自己的 Google Cloud Shell** 完成，不需要在电脑安装开发工具，也不需要 GitHub 帐号。

你只需要：

- 一个 Google 帐号（建立 Firebase 专案、存放资料）。
- 一个 Cloudflare 帐号（放网站）。
- 首位管理员可以收信的 email。

精灵只安装**核心功能**：登入、同工管理、服事表。行事历、照片辨识、通知与每日灵粮先不开启，之后可由技术同工依[部署指南](deployment.md)另外设定。

## 开始之前

- 云端资源、资料与帐单都属于你们教会自己的帐号。精灵**不会绑定付费帐单，也不会升级付费方案**；如果平台要求付费或受组织政策限制，精灵会停下来说明原因。
- 打开 Cloud Shell 时，Google 会先问是否「信任存放区」：**一定要勾选再按「确认」**。画面左上角若显示「暂时模式」，代表没勾到：请按 Cloud Shell 右上角的「⋮」，点选单里打勾的「暂时模式」，再按「停用」。Cloud Shell 重新启动并请你按「授权」后，回到安装说明页重新按「Open in Cloud Shell」，勾选「信任存放区」再照教学做。
- 接著会跳出 Google 官方的「授权 Cloud Shell」视窗，请按「**授权**」，不要按拒绝。
- 第一次会下载约 1–2 GB 的工具，需要几分钟到十几分钟。
- 中途有两处要**本人在 Firebase 官网操作**，精灵会停下来说明：这个 Google 帐号第一次用 Firebase 时要同意 Firebase 条款（每个帐号只做一次），以及启用 Firebase 登入功能。各约一两分钟，见第 4 步的「待本人操作」。
- 精灵只建立**全新的专案**，不会接管或修改你们已经在用的网站或资料库。
- 安装纪录存在 Cloud Shell 里这份程式的 `.local/install/`，只有你自己看得到。中断后可以接续，不会重复建立专案。

## 1. 启动精灵

> **画面左边那一大排资料夹和档案不用理它**，那是程式本身。整个安装只会用到右边这份教学，和下方的黑色终端机。

> **Cloud Shell 一打开可能就跳出「授权 Cloud Shell」视窗，请按「授权」。** 这是 Google 官方的视窗，让 Cloud Shell 用你自己的 Google 帐号建立专案；按「拒绝」会让后面的步骤无法进行。之后若再出现同样的视窗，也一样按「授权」。

**不用找程式在哪个资料夹**。按下方指令卡右上角的「在终端机执行」图示（小终端机），然后在黑色终端机按一次 Enter。它会寻找已下载的程式；如果没有，就从 GitHub 下载后启动。只需做这一次，不要逐字输入指令。

```sh
bash -c 'd=; [ -f scripts/start-installation.sh ] && d=$PWD; [ -z "$d" ] && s=$(find "$HOME" -maxdepth 7 -type f -path "*/church-staff-pwa*/scripts/start-installation.sh" -print -quit) && [ -n "$s" ] && d=${s%/scripts/start-installation.sh}; if [ -z "$d" ]; then d=$HOME/cloudshell_open/church-staff-pwa; mkdir -p $HOME/cloudshell_open && git clone -q --branch main --single-branch https://github.com/hansli112/church-staff-pwa.git "$d" || exit 1; fi; grep -q "pull --ff-only --quiet origin" "$d/scripts/start-installation.sh" || git -C "$d" pull -q --ff-only origin main; exec bash "$d/scripts/start-installation.sh"'
```

如果终端机显示红色错误，先停下来，不要重复按「执行」。

第一次会下载约 1.5 GB 的工具，终端机会显示目前是第几步和下载进度条，通常需要 3–10 分钟。下载进度暂停不代表当机；若超过五分钟完全不动，记下画面上的错误讯息再求助，不必开第二个终端机。重新开启教学时，只要再按同一张指令卡；程式档案未被修改、也没有待接续的安装时，启动工具会自动更新。

准备完成后，终端机会显示一个私人连结。**只在你自己的浏览器开启，不要分享给别人**；这个连结 15 分钟内要开启。第一次点开时 Google 会先确认你的帐号，画面可能请你「再点一次」：回到 Cloud Shell 分页，再点同一个连结就会开启。

## 2. 连接帐号

在精灵页面：

1. 按「连接 Google」，接著切到 Cloud Shell 分页。出现「Authorize Cloud Shell」时按 **Authorize**，选这次要用的 Google 帐号。没出现就回精灵再按一次「连接 Google」。精灵会显示已连接的帐号；**不是你要用的帐号就先停下**，照精灵上的说明切换帐号后重开教学。
2. 按「连接 Cloudflare」，再按「开启官方授权页」。在 Cloudflare 官方网页**输入精灵显示的代码**（页面说的「terminal」指的就是精灵），按 Continue。还没登入的话，这时才会请你登入，登入后按 **Authorize**。看到「Authorization granted」就完成了，页面上其他说明（例如 AI 工具）都不用理。代码约 5 分钟内有效，精灵会倒数；过期就再按一次「连接 Cloudflare」取得新代码，不要授权旧代码。
   - **还没有 Cloudflare 帐号**：在登入页按「Sign up」免费注册，Cloudflare 会寄一封验证信，点信里的连结完成验证。之后回到精灵，**重新按一次「连接 Cloudflare」**拿新的代码。

两边的密码都只在 Google 与 Cloudflare 官方网页输入，精灵不会看到。

## 3. 填写教会资料

- **教会名称、简称**：显示在 App 和手机桌面图示上。
- **教会 Logo（选填）**：选一张图片（PNG 或 JPG，正方形最好）和底色，会用在网站和手机桌面的图示，画面上会先预览。不选就用预设图示，之后更新时也能再换。
- **网站名称**：网址会是 `网站名称.pages.dev`，同工用这个网址登入，所以取个好记的，例如 `hope-church-staff`。只能用英文小写、数字和连字号（-），**建立后不能更改**。这个名称如果已经被别的 Cloudflare 帐号用过，Cloudflare 会在后面自动加几个字，实际网址以完成页为准。
- **教会时区**：决定服事表的日期，台湾是 `Asia/Taipei`。
- **资料库地区**：资料储存的位置，台湾可选「台湾 · asia-east1」。**建立后不能直接更改。**
- **每周聚会**：每种聚会的名称与固定星期。先填目前有的就好，装好之后管理员可以在 App 的「我的」→「聚会设定」新增、改名、改星期或停用。
- **首位管理员**：姓名与 email。精灵不会要你设定密码。

按「检查并预览安装」。

## 4. 确认并开始安装

仔细核对画面上的新专案、资料地区与管理员 email，勾选两个确认项目，再按「确认并开始安装」。

安装过程会依序建立专案、资料库、登入功能、网站，并寄一封设定密码信给管理员。请保持 Cloud Shell 分页开启。

### 如果显示「稍后接续」

Google 可能还在建立资源，或已收到建立请求但没回复结果。**不要重新开始新的安装**；等 3–5 分钟后按「稍后接续安装」，精灵会先读回实际状态，不会重送建立请求。

### 如果停在「待本人操作」

有些平台设定必须由本人在官方网页确认，例如第一次启用 Firebase 登入功能。画面会显示原因和「开启官方设定页」按钮。在官方网页完成后，回到精灵按「核对后接续安装」。

从没用过 Firebase 的 Google 帐号，会在「将 Firebase 加入新专案」这一步停下来，因为 Google 规定要本人同意 Firebase 条款。每个帐号只需做一次：照画面指示到 Firebase 官网，不要在「输入专案名称」栏打字，改按最下方的「将 Firebase 新增到 Google Cloud 专案」，选精灵建好的「Church Staff」并同意条款，回来按「核对后接续安装」即可。

### 如果中途关掉了

不小心在终端机按到 Ctrl+C、重新整理或关掉 Cloud Shell 分页，精灵就会停下来；这时精灵页面重新整理会看到英文的「Unable to forward your request to a backend」。进度都还在，不用另外输入 `gcloud auth login` 等指令：

重新执行第 1 步（按同一张指令卡），点终端机给的**新**连结，连接**同一组** Google 与 Cloudflare 帐号，在「接续之前中断的安装」选择原本的纪录。精灵会先核对云端实际状态，不会另建专案。

## 5. 完成后验收

1. 到管理员信箱找 Firebase 寄的英文信（主旨含「Reset your password」）。**这封信多半会在垃圾邮件**，找到后可标成「不是垃圾邮件」。用信中的连结设定密码。
2. 开启精灵显示的网址，用管理员 email 和刚设定的密码登入。
3. 到「服事表」按右上角铅笔，再按右上角清单图示「服事项目设定」，新增一个服事项目（例如「招待」），按 ✓ 储存。
4. 到下方「我的」→「帐号管理」新增一位同工：设定牧区，并在该牧区的「参与服事」勾选刚才的服事项目。
5. 回「服事表」→ 铅笔，在某个日期按「新增服事项目」替这位同工排班，重新整理后仍看得到。资料权限规则可能要几分钟才完全生效。

精灵完成页也列了同样的检查项目。只是测试安装的话，完成页的「如何删除」只列出这次建立的 Cloudflare 网站与 Google 专案：Cloudflare 删除是立即永久；Google 专案关闭后约 30 天内仍可还原。

没收到信时，在网站登入页按「**忘记密码？**」，输入管理员 email 再寄一次。**不要另外建立管理员。**

## 6. 分享给同工、保存交接卡

- **分享给同工**：完成页有一段可以直接贴到 LINE 群组的讯息。里面的连结带有 `?openExternalBrowser=1`，LINE 会改用手机的浏览器开启；在 LINE 内建浏览器里没办法加到主画面，关掉后也常要重新登入。同工第一次开启时，首页会提示怎么加到手机主画面。
- **交接卡**：完成页列出这个网站挂在哪个 Google 帐号、Cloudflare 帐号底下，以及专案 ID 与安装识别码。**请截图或复制，存到教会的共用资料夹。**以后要更新、除错或交接给别人都需要这些资料。

## 7. 更新到新版本

有新版本时，管理员在 App 的「我的」页面会看到「有新版本可以更新」，列出这次改了什么。更新方式：

1. 照第 1 步重新开启精灵（同一张指令卡，它会自动下载最新版）。
2. 照第 2 步连接**当初安装用的** Google 与 Cloudflare 帐号。不确定是哪一组，看交接卡。
3. 在「已经装过了？更新到新版本」按「**寻找已安装的网站**」，选你们的网站。
4. 核对网站网址，勾选确认，按「**开始更新**」。

更新**只换网站程式和资料存取规则**，同工帐号、服事表和所有资料都不会变。建置新版大约 10–20 分钟，这段时间旧版照常可以用；中途停止或失败也不会影响旧版，重新按「开始更新」即可。已经是最新版的话，精灵会直接告诉你，不会重新建置。

更新完成后，同工重新整理网页，或把手机桌面上的 App 关掉重开，就会换到新版。

### 顺便换教会 Logo、设定自订网址

更新时展开「换教会 Logo、设定自订网址（选填）」：

- **教会 Logo**：选一张图片（PNG 或 JPG，正方形最好），再选底色。精灵会自动做出网站和手机桌面需要的各种尺寸，并显示预览。之后的更新会沿用这个 Logo；想换回来按「改回预设图示」。手机上已经加到桌面的图示不会自动换，要删掉重新加一次。
- **自订网址**：教会自己有网域（例如 `hope-church.org`）、而且有人能改 DNS 时才用。填一个子网域，例如 `staff.hope-church.org`；不能只填 `hope-church.org`。更新完成后，精灵会列出要新增的一笔 **CNAME** 记录（名称 `staff`、目标是原本的 `.pages.dev` 网址），请到网域注册商或 Cloudflare 的 DNS 页面加上。通常几分钟到几小时生效，生效前继续用原本的网址。

### 同工帳號管理

精靈會在你們的 Google 專案建立一個只能管理 Firebase 登入帳號的服務帳號（`church-accounts`），把它的金鑰以加密方式存進 Cloudflare 網站設定。網站用它在新增同工時建立登入帳號、刪除同工時一起刪掉登入帳號，所以刪掉的 Email 可以再加回來。金鑰不會出現在網頁裡，也不會存在精靈的安裝紀錄。

用 Google Workspace 機構帳號安裝時，機構可能不允許建立服務帳號金鑰；精靈會略過這一步，網站照常運作。這時在 App 刪除同工後，要用同一個 Email 重新加入，得先到 Firebase 主控台的 Authentication → Users 刪掉那個 Email（App 會顯示這段說明）。

## 目前限制

- 这是第一版，云端实际安装流程还在验证中，遇到问题请到专案 GitHub 开 issue，附上画面上的错误说明（**不要贴上任何密码、连结中的代码或授权码**）。本专案不提供客服或保证回应时间。
- 行事历、照片辨识、通知与每日灵粮等选用功能，目前仍需技术同工依[部署指南](deployment.md)处理。版本更新、教会 Logo 与自订网址见上面第 7 步。
